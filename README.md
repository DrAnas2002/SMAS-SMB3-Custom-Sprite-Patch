# SMAS SMB3 Custom Sprite Patch
A basic patch for the standalone Super Mario Bros. 3 ROM from [Yoshifanatic's SMAS+W disassembly](https://github.com/DrAnas2002/SMW-SMAS-SMASW-Disassembly-LINUX) that allows you to replace vanilla sprites with completely custom sprite codes! Please see 'custom_smb3_sprites_patch.asm' for detailed instructions on how to use the patch, but know that the disassembly is **strictly required!**
